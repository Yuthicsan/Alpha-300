**# Day 24: Binary Search Variants (First + Last Occurrence)**

**## Folder Contents & Summary**

| Type | File | Approach | Time | Space |
|---|---|---|---|---|
| Primary 1 | `find_first_last_position.py` | Perform two binary searches to find the first and last positions of a target in a sorted array. | O(log n) | O(1) |
| Primary 2 | `count_occurrences.py` | Find the first and last occurrences of an element using binary search, then calculate the total count. | O(log n) | O(1) |
| Primary 3 | `floor_ceiling_sorted_array.py` | Use binary search to find the greatest element less than or equal to the target and the smallest element greater than or equal to it. | O(log n) | O(1) |
