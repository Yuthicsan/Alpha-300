**# Day 28: Binary Search on Condition (Parametric Search)**

**## Folder Contents & Summary**

| Type | File | Approach | Time | Space |
|---|---|---|---|---|
| Primary 1 | `capacity_to_ship_packages.py` | Binary search the minimum shipping capacity and check whether all packages can be shipped within the given number of days. | O(n log S) | O(1) |
| Primary 2 | `koko_eating_bananas.py` | Binary search the minimum eating speed and check whether Koko can finish all banana piles within the allowed hours. | O(n log M) | O(1) |
| Primary 3 | `allocate_minimum_pages.py` | Binary search the minimum possible maximum pages and check whether books can be allocated contiguously among students within that limit. | O(n log S) | O(1) |
