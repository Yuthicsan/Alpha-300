# Day 4: Running State in One Pass

## Folder Contents & Summary

| Type | File | Approach | Time | Space |
|---|---|---|---|---|
| Primary 1 | `running_sum_1d_array.py` | Maintain a running total and store each cumulative sum in the result array. | O(n) | O(n) |
| Primary 2 | `max_consecutive_ones.py` | Track the current streak of ones and update the maximum whenever a `1` is encountered. Reset the current streak when a `0` appears. | O(n) | O(1) |
| Primary 3 | `best_time_to_buy_and_sell_stock.py` | Track the minimum price seen so far and calculate the maximum possible profit at each price. | O(n) | O(1) |
