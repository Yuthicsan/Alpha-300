**# Day 20: Counting Sort (Implement from Scratch)**

**## Folder Contents & Summary**

| Type | File | Approach | Time | Space |
|---|---|---|---|---|
| Primary 1 | `counting_sort.py` | Build a frequency array manually, then reconstruct the sorted array using element counts. | O(n + k) | O(k) |
| Primary 2 | `sort_colors.py` | Count the occurrences of 0, 1, and 2 manually, then overwrite the array in sorted order. | O(n) | O(1) |
| Primary 3 | `sort_array_0s_1s.py` | Count zeros and ones, then overwrite the array with the appropriate number of each value. | O(n) | O(1) |
