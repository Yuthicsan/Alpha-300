**# Day 15: Bubble Sort (Implement from Scratch)**

**## Folder Contents & Summary**

| Type | File | Approach | Time | Space |
|---|---|---|---|---|
| Primary 1 | `bubble_sort.py` | Use nested loops to compare adjacent elements and swap them whenever they are in the wrong order. | O(n²) | O(1) |
| Primary 2 | `bubble_sort_early_exit.py` | Use a swap-tracking flag to stop early when a complete pass makes no swaps. | O(n²) worst case, O(n) best case | O(1) |
| Primary 3 | `sort_array_by_parity_bubble.py` | Compare adjacent elements using nested loops and swap whenever an odd number appears before an even number. | O(n²) | O(1) |
