**# Day 17: Insertion Sort (Implement from Scratch)**

**## Folder Contents & Summary**

| Type | File | Approach | Time | Space |
|---|---|---|---|---|
| Primary 1 | `insertion_sort.py` | Build a sorted portion by shifting larger elements right and inserting the current element into its correct position. | O(n²) | O(1) |
| Primary 2 | `insertion_sort_nearly_sorted.py` | Shift elements only when necessary to insert each element into its correct position in a nearly sorted array. | O(n²) worst, O(n) best | O(1) |
| Primary 3 | `sort_array_0_1_2.py` | Sort an array containing only 0, 1, and 2 using manual insertion and shifting, without built-in sorting. | O(n²) | O(1) |
